## ❖ About

**CryonixLauncher V4** is an Android Minecraft launcher project focused on a customizable interface, flexible configuration, and a smooth mobile launcher experience.

Our goal is to provide a clean, modern launcher with useful customization options and support for compatible Minecraft versions and mod loaders.

## ✦ Features

* **Modern UI** — A dark interface with soft-blue accents.
* **Instance Management** — Organize and manage separate game instances.
* **Version Selection** — Choose from supported Minecraft versions.
* **Mod Loader Support** — Vanilla and Fabric support where implemented.
* **Rendering Options** — Configuration options for compatible rendering backends.
* **Account Management** — Manage supported account types.
* **Crash Assistant** — Help users understand crash logs and troubleshoot common issues.
* **Cursor Customization** — Customize the in-game cursor where supported.
* **Skin and Cape Features** — Planned customization features, depending on implementation and service compatibility.

*Feature availability depends on the current build, backend compatibility, and project implementation.*

## 📦 Getting Started

### Clone the repository

```bash
git clone https://github.com/cryonixlauncherteam/CryonixLauncherV4.git
```

Open the cloned project in **Android Studio**, allow Gradle synchronization to finish, and resolve any SDK requirements shown by the IDE.

### Build the project

1. Open the project in Android Studio.
2. Wait for Gradle sync to complete.
3. Select the appropriate build variant.
4. Build the APK using **Build → Build APK(s)**.

The build may require additional SDKs, native dependencies, or project-specific configuration.
